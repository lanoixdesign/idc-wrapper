# Code de conduite / Code of Conduct

Ce projet adopte le [Contributor Covenant](https://www.contributor-covenant.org) version 2.1
(adaptation courte FR + EN).

## Notre engagement

Nous nous engageons à faire de la participation à IDC Wrapper une expérience
**sans harcèlement**, quels que soient l’âge, le corps, le handicap visible ou
invisible, l’ethnicité, les caractéristiques sexuelles, l’identité et
l’expression de genre, le niveau d’expérience, l’éducation, le statut
socio-économique, la nationalité, l’apparence, la race, la religion, ou
l’identité et l’orientation sexuelles.

## Standards

Exemples de comportements attendus : empathie, respect des opinions divergentes,
feedback constructif, responsabilité.

Comportements inacceptables : langage ou images sexualisés, trolling, insultes,
harcèlement public ou privé, doxxing, autres conduites inappropriées en milieu
professionnel.

## Application

Les mainteneurs peuvent retirer, éditer ou rejeter commentaires, commits, code,
wikis, issues et autres contributions qui ne respectent pas ce Code, et exclure
temporairement ou définitivement tout contributeur pour comportements jugés
inappropriés.

Signaler un incident : ouvrir une issue privée si disponible, ou contacter
l’auteur du dépôt via GitHub (@lanoixdesign).

## English blurb

We follow Contributor Covenant 2.1: be respectful, no harassment. Maintainers
may moderate contributions. Report issues to the repository maintainer
(@lanoixdesign) on GitHub.
