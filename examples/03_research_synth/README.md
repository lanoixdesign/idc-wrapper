# 03 — Synthèse de recherche

## Sans IDC
L'agent digresse, invente des citations, reformule sans source.
Risque élevé d'hallucination bibliographique.

## Avec IDC
Sources → synthèse → limite assumée → **effondrement**.
Les citations inventées du scénario mock restent hors journal IDC.

## Bénéfice
Synthèse bornée, limite explicite, moins de tokens, honnêteté sur l'incertitude.

## Exécuter

```bash
python examples/03_research_synth/run_mock.py
```
