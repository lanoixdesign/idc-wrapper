# Sécurité / Security

## Signaler une vulnérabilité

Merci de **ne pas** ouvrir d’issue publique pour une faille de sécurité.

1. Contacte le mainteneur via GitHub Security Advisories sur
   [lanoixdesign/idc-wrapper](https://github.com/lanoixdesign/idc-wrapper)
   (si activé), ou un message privé à @lanoixdesign.
2. Inclus : description, impact, étapes de reproduction, version / commit.
3. Délai de réponse indicatif : 7 jours ouvrés.

## Périmètre

- Code Rust / Python de ce dépôt.
- Fuite involontaire de secrets dans exemples ou CI (clés API, tokens).

Hors périmètre : sécurité des backends LLM tiers (OpenAI, Ollama, etc.).

## English

Please use private disclosure (GitHub Security Advisory or maintainer DM).
Do not file public issues for vulnerabilities. Third-party LLM APIs are out of scope.
